# 스탬핏 (StampFit)
￼

> **복잡한 기록 없이 간단하게 기록하는 나만의 운동 캘린더**

* 운동일지를 달력에 기록하고, 월별 리포트 카드로 한눈에 모아보는 피트니스 캘린더 앱

## Tech Stack
- **Framework**: React Native + Expo
- **Language**: TypeScript
- **Styling**: NativeWind (Tailwind CSS)
- **Database**: Local SQLite (`expo-sqlite`) + Supabase
- **Widget**: iOS : SwiftUI Widget / Android : Android Native Widget

## Main Features
- 🗓️ **운동 캘린더**: 운동일지 캘린더 기록, 운동한 날짜 및 부위 체크
- ⚡ **심플 기록**: 복잡한 세트 입력 기능 없이 간편하게 운동 기록
- 📇 **월간 리포트 카드**: 한 달의 운동량, 연속 달성일수, 집중 부위를 카드로 요약 및 SNS 공유
- 🔄 **싸이클 지정**: 원하는 주기를 설정하여 운동 일정을 관리 -> 싸이클에 맞는 다음 운동부위 표시
- 📱 **홈 위젯**: 앱을 켜지 않고도 홈 화면에서 확인하는 연속 운동 스트릭과 오늘 할 운동 체크
